# 发行范围与验收合同

## 正式入口

唯一支持的完整生产入口是顶层 `RUN.ps1`，它调用 `payload/02_code/reconstruction_dual_v1_20261009/run_target_delivery.py`。包内保留的研究、诊断和历史兼容脚本不是发行 API，单独运行它们不构成离线交付验收。

## 成功条件

1. 原始 MCAP 身份在运行前后保持不变。
2. `STATE.json` 与 `RESULT.json` 的终态为 `dual_target_outputs_complete`。
3. `target/DELIVERY_RESULT.json` 通过双路产物、相机、尺度、网格、点采样和预览检查。
4. `EXCEPTION_LEDGER.json` 保留所有原生非零子阶段、有限恢复、人工干预和网络拒绝记录。
5. 3DGS 与 PGSR 使用同一轮实际准入相机和尺度接口。
6. 运行期间不调用 LLM、VLM、云 API，不下载依赖、代码或权重。

## 失败条件

依赖缺失、原始数据变化、设备/标定不匹配、数值或几何门槛未满足、未知网络访问、GPU 所有权冲突、输出目录非空或未知异常都会明确失败并保留证据。失败后修改代码再运行属于新的开发周期；不能将其写成原运行的自动恢复。

## 当前证据边界

四份既有传感器录制已经从头完成，但这只确认当前格式和本机运行环境的工程闭环。没有独立 GT 的私有录制不支持绝对精度结论；没有完成跨机器部署、不同传感器协议或大规模跨类别公开数据集验证。
