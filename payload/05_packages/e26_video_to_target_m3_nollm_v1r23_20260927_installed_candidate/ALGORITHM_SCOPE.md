# v1r23 算法范围与证据边界

本文件的 S00–S08 上游描述沿用 v3r1 结构；完整入口在 S08 后继续执行 M3，并检验高于地面的度量稀疏轨迹是否被 M3 保留。

## 统一数据流

```text
S00 原始 MCAP 身份冻结
  -> S01 机器选帧与视觉工作区
  -> S02 非语义机器图像清点
  -> S03 米制轨迹提取或 LIO fallback
  -> S04 轨迹绑定
  -> S05 Sim3 米制对齐、输入血缘联检与独立相机几何准入
  -> S06 PGSR 训练
  -> S07 数值 ROI、三候选 TSDF 和几何/稀疏支持选择
  -> S08 重力约束地面删除
  -> S08 observed-surface triangle mesh
  -> S08 离线点云预览
  -> M3 共用去地面、接触保护和组件筛选
  -> 最终离线三维预览与质量回执
```

两个配置共享输入身份、SfM、米制对齐、PGSR、S08 地面规则、mesh 实体化、预览和回执框架。

Sim3 的 `0.2 m` 条件用于全局米制对齐和异常对应拒绝。它不单独决定 PGSR 相机集合。相机还要满足版本化策略中的三角化点数、图像网格覆盖和二维支撑范围，并且注册清单、位姿先验、Sim3、残差回执和稀疏模型必须通过同源校验。

## ReliableLidar 配置

这个配置来自 Tesla v2 实跑改进：

1. 候选帧先通过清晰度和曝光门，再以 12 个水平环绕方位扇区保证覆盖，并用相机高度、轨迹半径和时间多样性补齐；
2. 融合候选的 PGSR 像素通过 alpha、法线视角、ROI 和至少三个邻视角的深度重投影一致性检查；另生成严格视觉候选和宽视角视觉候选；
3. `/localization/lidar/points_registered_full` 回波按时间配对，在 2 cm 体素中要求至少三个独立扫描支持；
4. 同时形成严格视觉深度、宽视角视觉深度和雷达融合 TSDF；仅当融合结果明显碎裂、视觉结果连通且米制稀疏支撑保持在固定门内时，选用视觉网格，否则保留融合网格；
5. 地面 RANSAC 结果必须与独立稀疏点高度估计一致。

`ReliableLidar` 的 ROI 先从每个视频的米制稀疏点估计光轴焦点和地面，再由近邻点距的稳健分位数自适应确定三维密度邻域。主簇必须至少占候选点 75%、包含光轴焦点，离地 0.08 m 的候选区域须覆盖更高离地阈值的核心支持；高阈值区域不得向低阈值 ROI 外扩超过 0.20 m。高阈值区域因低箱体消失而收缩只记录为诊断。低位连续支持扩充横向 ROI；宽度/相机深度比只作为诊断量，不是通过门。回执记录候选范围、所选范围、邻域尺度、主簇占比、边界漂移和外扩量；不按物体名称或采集文件名分支。

S07 选择规则在三份候选网格生成后才执行：融合候选的主连通面面积占比低于 0.95 且连通片多于 1,000 个；可采用的视觉候选主连通面占比至少 0.98 且连通片不多于 1,000 个；在 ROI 内、离空间地面高于 0.10 m 的米制稀疏点中，5 cm 内支撑至少 95%，相对融合候选下降不超过三个百分点。严格视觉候选要求渲染 alpha 至少 0.60、法线视角不超过 60°；宽视角候选沿用旧版 80° 视角且不施加 alpha 门。两者都合格时，仅当宽视角候选新增三角面处于 5%–25%、稀疏支持不低于严格候选时才选宽视角，否则选严格候选。回执保留三份网格、指标和选择理由。这些门来自当前场景的开发对照，并非未知场景的精度保证。

注册雷达锚点要求全序列至少 10,000 个稳定点。每帧少于 10 点的情况仅在其不为空、位于序列内部、相互不相邻且数量不超过总帧数 2% 时作为孤立弱帧继续，并在回执逐帧披露；其余情况停止。弱帧不从邻近时间借点，也不以人工点云或语义补全替代观测。TSDF 仍使用多视角深度门和全序列 LiDAR 投影支持门。

TSDF 将注册雷达锚点与原始已选图像清单一一核对；PGSR 训练视图必须等于准入训练图像，且都属于已有雷达锚点的子集。因 Sim3 或几何门控排除的已选帧保留在原始锚点回执，但不参与 TSDF 积分，并在 TSDF 回执列出。PGSR 启动要求至少 6,144 MiB 实际空闲显存及距 14,336 MiB 运行占用上限至少 5,120 MiB 余量，训练时仍每 5 秒监控资源。

S06 先在度量稀疏点的低位空间包络上拟合跨越双轴的地面平面，核对内点网格数、占比、倾角、残差和相机离地高度。若旧高度模式比该平面高超过 0.15 米，则改用空间平面高度推导 ROI；否则保留原高度模式。S08 与 M3 从当前 S07 网格拟合地面，并要求与该独立稀疏平面一致；当宽范围网格拟合到箱体顶面或其他局部面时，改在空间平面 ±5 厘米内取候选，再按网格支持、横向范围、ROI 跨度和必要时原始注册雷达证据验收。没有足够支持时失败，不静默选择高处平面。

该配置需要恰好一个嵌入式里程计连接和一个注册 LiDAR 连接。缺少契约时不得伪造 fallback 成功。

## LegacyPgsr 配置

这个配置保留旧 S00–S08 包的兼容路线：

- 嵌入式里程计存在时直接提取米制上下文；
- 不存在时运行原始 LiDAR/IMU 的 LIO fallback；
- 使用相机光轴稳健交点和确定性三维密度主簇派生 ROI；
- PGSR 深度进入常规 TSDF，再执行同一 S08 地面三角形规则。

Legacy 配置不包含 Tesla v2 的注册 LiDAR 锚定和逐像素多视角门控。

## S08 mesh 输出的精确定义

S08 mesh 是 S07 TSDF 三角网格执行固定地面规则后的直接产物：

- 删除低于地面有符号高度门且近似平行于地面的三角形；
- 删除完全处在无条件低位伪影带内的三角形；
- 删除未再被三角形引用的顶点；
- 保留已有三角拓扑、顶点颜色，并重新计算顶点法线；
- 不执行 S09 连通组件过滤；
- 不做 Poisson 重建、孔洞填充、对象模板拟合或表面补全。

随后从同一个 S08 mesh 均匀采样点云用于浏览器显示。点云是显示派生物，mesh 是几何主产物。

## 机器失败策略

以下条件直接失败并保留回执或日志，不进入伪成功：

- MCAP SHA-256 与调用方提供的身份不一致；
- 外部 Python、COLMAP、WSL PGSR 或 CUDA 不可用；
- SfM、米制绑定、Sim3、独立相机几何准入或输入血缘不满足版本化门；
- ReliableLidar 缺少注册 LiDAR topic、扫描配对或稳定锚点；
- ROI、TSDF 或地面拟合没有足够数值证据；
- M3 大量丢失了 S07 和度量稀疏轨迹共同支持的高于地面目标表面；
- S08 mesh 为空、含非有限值或无法写出；
- Viewer 验证失败，或回执显示执行了 S09。

## 明确不包含

- 大语言模型、视觉语言模型和运行时人工视觉判断；
- SAM/SAM2 对象掩膜；
- 已知车辆或纸箱尺寸、CAD 模板；
- 未观测表面推断、玻璃补面和水密化；
- S09 及后续物理面候选流程；
- 独立三维真值和尺寸精度验收。

`complete_s08_observed_surface` 只表示程序成功生成了经过 S08 规则的观测表面网格和离线预览，不表示完整或可制造的最终物体。
