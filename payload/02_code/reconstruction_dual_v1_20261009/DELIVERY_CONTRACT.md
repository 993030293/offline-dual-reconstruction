# 双输出离线交付契约

输入是带图像、标定和同步原始传感器的 MCAP。原文件有记录粗运动与配准扫描时读取这些原始话题；没有时，必须由本次运行的已验收粗运动分支生成来源。默认 AdaptiveSensor 使用当前质量/粗位姿/覆盖初选和后续视觉增帧；两路共用成功注册图像、完整内参和世界坐标。普通独立视频没有这些传感器来源时，不自动具备米制尺度。四视频从原始 MCAP 冷启动不等于四次重新运行完整 Point-LIO：当前七月录制使用原始陀螺与局部扫描生成粗运动，另外三段读取原文件中已有的里程计与配准扫描，原生产者和跨录制标定有效性仍需独立确认。

目标点云必须由当前 PGSR 模型生成深度，实际执行数值 ROI、三候选表面选择、支持保持、M3 去地面和组件筛选。全场景 TSDF、直接高斯中心、简单显示裁剪或增加采样点数不能代替这条几何路线。旧 Box2 结果只说明交付形态，不能复用其模型作为新 Box1 输入。

M3 的地面支撑和目标锚点使用同一传感器来源选择。原 MCAP 带配准扫描时读取原话题；当前运行重估粗运动时，显式传递本次 `raw_sensor_backend/RESULT.json`，从完整扫描验证地面，禁止用已去地面的目标锚点代替。输入必须绑定本轮 PGSR 模型根目录、原始文件身份、唯一时间戳和显式无大模型来源；跨运行目录或不完整来源即失败。这个接口不改变地面点距离、至少30个独立支撑扫描、空间范围或覆盖门槛。

M3 的物理地面支撑先使用既有每10扫描抽样；若证据不足，最多追加一次同来源全部独立扫描检查，重新计数而不重复累加首轮点或扫描。首轮不足与最终实测指标同时写入地面回执和异常账本；完整检查仍不足则失败，不能改变1,000近地面点、30独立支撑扫描、单扫描20点或既有空间覆盖门槛。这个有界证据扩展由离线代码预先决定，默认低层兼容接口仍保留旧抽样行为。

## 视觉选入与传感器参与

相机全部注册仍可能缺少足够的有效三维观测。必需相机重定位后，离线代码依据当前模型重新检查原生观测门槛；未注册或已注册但低于原生门槛时，最多调用一次既有特征增强与真实几何重定位。后者使用刚产生的模型、特征数据库和重新计算的弱帧名单，覆盖重定位后新出现的弱帧，不复用旧名单。恢复沿用原共享时间预算，保留有效几何轨迹并完成全体必需相机的最终点重建验收；不放宽30观测门槛、不删必需帧，也不提前准许训练。初次不足、恢复轨迹和最终失败均保留。

v24 普通重定位同样先验证当前全部真实特征坐标和索引与当前数据库一致，再按原生重投影和三角角度门槛过滤几何。过滤后再次计算弱帧；仍不足时沿用上述一次特征恢复，完整时将已过滤的真实轨迹交给增量三角化。初次全点重建仍清空旧点，只有本次重定位产生、实际验证过的几何可保留；最终仍重新验收全体必需相机的30观测、固定内参、当前三角化输入位姿和原360秒完整预算。不能用重定位前的暂时观测数代替最终结果。

AdaptiveSensor 的图像不因 LiDAR 缺失而被删。图像有真实视觉注册和质量证据时继续贡献；时间范围外或稳定锚点不足的帧不贡献雷达项。60 ms 配对、2 cm 稳定体素、三个独立扫描、单帧雷达 10 锚点、独立扫描去重总量 10,000 等条件见 ADAPTIVE_SENSOR_CONTRACT.md。三候选、多视图和最终稀疏支持仍需验收；不能自动把失败改写成视觉成功。

目标 ROI 的光轴拟合使用有方向的相机射线，并将原有全相机 95% 前方要求加入拟合约束。近裁剪距离来自已安装渲染器，不从单一录制调参；拟合不翻转相机方向、不删除相机，也不写入人工目标坐标。原地面支撑、空间地板、密度组件、ROI 边界与高度限制全部继续执行。前方交集不可行或数值求解未完成时明确失败，不能改变分母或跳过后续检查；旧参考包与其原始拟合实现保留。

数值恢复的异常账本以本轮米制契约声明的协议版本核对实际恢复回执，因子数量、共同观测和世界坐标恢复检查保持不变。协议缺失或版本不一致不计为通过；恢复后的成功不抹去原始失败，也不允许宣称零失败。

显式 ReliableLidar 是旧每帧覆盖对照，其失败继续保留。新契约验收与旧门槛验收分开。VisualTargetDiagnostic 可以交付诊断页面，但不能写成融合完成。判定使用回执中的 profile，不能仅因 strict_ReliableLidar_profile_completed=false 就把新传感器契约误标成视觉诊断。

## 运行与证据边界

统一入口 schema 3 使用全新独立目录；成功阶段可在冻结输入下恢复，失败阶段不静默续跑。原始文件和唯一产物保护不变。原始 Box1 已完成的前端和训练可以在纠正下游时复用，但这种验证属于同一次运行的下游修复，不能宣称最终版再次完整冷启动。

目标 TSDF 为 5 mm 体素、20 mm 截断、10 m 深度范围；这些参数以及相机对齐残差和点数均不等于测量精度。稀疏支持是与视觉共享输入的自一致性验证，无独立 GT 时不能报告尺寸精度、完整率或多物体泛化。原里程计生产者未确认，没有新全序列 LIO 重放。

运行时必须纯离线，不调用大模型、云服务或下载依赖。仅本机预览允许 loopback；Python 和浏览器有显式网络约束，但未修改操作系统全局防火墙。实际检查本地 COLMAP、两路 GPU 依赖、原目标模块、PowerShell 7、Open3D/Scipy/Plotly 与 Node/Playwright；缺失即失败。

本机原生预览打包最多两次独立尝试，两次合计仍为原360秒。有限恢复仅针对完整资产校验后的同源相机或显示元数据传输错误，须有具体浏览器错误码、DOM/页面状态、原服务身份和已关闭浏览器/所属树证据。404、外部请求、原生资产、数量和程序错误、缺失日志及未结束进程继续失败。原失败写入native_packing/attempt_*/，异常账本按真实原始记录重新计算资格，RUN_REPORT保留恢复及根因未确认；完整验收仅接受逐路径绑定的预编码非零退出，不能全局放行失败。

进程归属的每一条祖先链接须核对PID与创建时间，孩子早于复用父进程时不得计入所属树或对其执行清理。原拒绝证据保留。表面采样的只读验收沿用原机器精度容差；float32距离拒绝只有在真实输出三角面的float64见证满足原界时才能被纠正，原查询结果仍保留。该纠正不增加几何观测或提供GT精度。

外部实现归原作者，许可证随交付保存；PGSR 的研究/非营利/非商业条款明确保留。当前只验证本机绑定环境，没有商业许可落实或移机部署验收。
