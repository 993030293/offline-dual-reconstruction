4. 用本轮已训练 PGSR 模型与完整 K 生成 ROI 内深度；恢复原来的严格视觉、宽视角视觉和雷达融合候选，以及原候选选择与稀疏支持约束。新选帧、批量质量计算、稀疏补边和共享相机能力保留；CPU 缓存、扫描去重缓存与逐阶段释放内存继续适配密集帧。显式视觉诊断单独保留，不能冒充三候选验收。
