# 新选帧与目标表面分支的传感器契约

版本：`visual_admission_independent_from_partial_lidar_v1`。本契约在该版本的新传感器诊断和三候选表面评估前写入独立运行目录，不用于追溯把旧失败标为通过。

初选继续使用图像质量、粗运动、位置与朝向覆盖、时间桥接；后续继续通过真实视觉注册纳入缺少粗位姿的合格图像。初选不能使用未来 SfM 位姿。后续视觉注册与全序列优化属于离线处理。两路训练共用同一个成功注册集合，不能因某帧缺少 LiDAR 就删掉其有效视觉观测。

默认 `AdaptiveSensor` 将视觉选入资格与 LiDAR 参与资格分开。每张图使用 60 ms 内最近的真实注册扫描；不配对的图仅保留视觉证据，不借用越界扫描，不外推位姿或伪造锚点。稳定锚点仍要求 2 cm 体素内至少三个独立扫描。多个图像使用同一扫描时，只算一次独立扫描，并只计算、缓存一份扫描锚点。单帧少于 10 个稳定锚点时，该帧的雷达项明确 abstain，图像不因此退出视觉分支。

传感器分支至少需要三个独立扫描和 10,000 个按扫描去重计数的稳定锚点；不满足则失败，不自动切换成成功的融合路线。后续三候选仍使用原实现的严格视觉、宽视角视觉和雷达融合。融合候选的视觉深度需至少三个邻视角支持，整体可信像素比例至少 5%，真实投影雷达像素累计至少 10,000。原候选选择、稀疏支持与边界裁剪规则保留；选中表面的稀疏支持比例至少为原规则的 95%。M3 去地面、接触保护、组件筛选和目标支持保持仍需实际验收。

`ReliableLidar` 是旧的每帧雷达覆盖契约，仅作为显式对照。其失败保留；新契约通过不意味着旧契约通过。`VisualTargetDiagnostic` 是显式视觉诊断，不能宣称雷达融合验收。

这些条件是工程自一致性要求。稀疏点与表面共享视觉输入，不能作为独立三维 GT。没有 GT 时不报告尺寸误差、重建完整率或通用物体精度。该版本仍未经过多物体数据验证，已有高度范围、地面假设和几何邻接规则的适用范围需要后续检查。
