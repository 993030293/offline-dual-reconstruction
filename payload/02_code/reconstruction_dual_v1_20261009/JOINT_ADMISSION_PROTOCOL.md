# 相机与三视图点的联合准入协议 v2

旧单次筛选在本轮 C1 中实际失败，日志、源码和部分输出均保留。这次修复改变筛选算法，不能宣称旧单次筛选协议通过；原始图、相机、点和失败继续保存在 full map 及 failures 中。

原因是依赖关系：剔除相机使点的轨迹变短；按既有三视图规则剔除点，又可能使邻接相机不满足既有几何门槛。单独判断一次相机支撑不能证明最终训练子图稳定。

新算法只在独立副本执行确定性的单调筛选：计算当前相机的原几何支撑，剔除不满足原条件的相机，按原点规则筛选，再重新计算支撑，直到没有改变。点坐标、相机位姿、内参和阈值不因筛选改变。不会手工指定图像、隐藏失败、采用两视图点 fallback、或递归放宽门槛。

每轮记录实际失去资格的相机、原因、点数和相机数。迭代上限是原相机数，必须单调减少；至少保留原 policy 的三十二相机、一万点，并额外要求最终相机不少于本次完整注册分母的原 policy 保留比例 90%。该比例以完整分母计算，不能通过缩小分母过关。触发下限则失败。

完成后仍使用原生导出的相机几何、投影、名单、完整内参、坐标不变和原生 PLY 回读检查。训练名单与排除名单必须完整分割 full map；两路共享全部实际准入相机。全图不删除，注册成功不自动等于训练合格。

本协议先于联合筛选试验冻结。C1 是开发录制，本次记录属于工程修复验证，不作为旧协议成功、未见数据泛化或独立 GT 精度证据。

## 最终针孔表示的候选扩展 v3

a0040_c0_july 的真实停止表明：原畸变图中的稳定子图，在原生去畸变后的图像网格中未必仍满足支撑要求。102 个不变观测的覆盖从四格变为三格，原最终检查正确拒绝；原始串行和加速网格算法在全部 1224 张相机上的结果一致。完整原失败、独立诊断、辅助诊断错误和原数值告警保留。

v3 在实际针孔模型生成后，以同一原政策同时检查畸变工作模型与针孔工作模型。任一表示支撑不足，就按既有联合准入规则在两个独立副本中同步排除该相机、维护原三视图点规则，再复查两种表示直到稳定。原完整注册分母、至少 90% 保留比例、32 张相机、10000 个点、30 个三角化观测、4 个网格及面积要求保持；不手工指定帧号，不降低条件，不缩小原分母。共享 rig 中无法单独排除而仍保留合格相机时继续拒绝。

开始前与结束后核对完整候选与保留子图的位姿、三维坐标、校准和观测身份。不得通过修改它们制造支撑。源与针孔表示的二维坐标按原生去畸变转换，不能将两个像素域的网格资格当成相同事实。

实际触发时保留 ORIGINAL_DESTINATION_SUPPORT_REJECTION.json、转换前两个候选模型、每轮依赖变化和完整排除名单；新产生的去畸变排除图像移入当前独立 export 的 excluded_undistorted_images，原 MCAP 与源图像不修改。完整米制图、原 PnP 拒绝和求解器告警保留，原候选最终支撑失败不能追溯为通过，也不能称零失败。

DESTINATION_JOINT_ADMISSION.json 只证明联合筛选结果，不授予训练准入。之后原最终 PINHOLE、图像名单、完整内参、几何支撑、有效投影、坐标不变与原生 PLY 回读检查继续执行；最终 TRAINING_ADMISSION 才交给两路共享输入。异常账本重新绑定原政策、完整分母、原拒绝和实际最终准入；独立共享输入审计从真实二进制针孔模型重算全部相机支撑。

当前 v3 属于开发候选，聚焦回归不等于正式接受。独立真实导出诊断、完整回归、新冻结源和四录制连续两轮八个新空根完整双输出验收仍必须完成；任何旧诊断产物不得进入新冷启动。当前状态以 CURRENT_PROGRESS.json 与逐项实际回执为准。
